
# Application Python de gestion des tâches

## Description
Ce projet est une application Python simple qui permet de gérer les tâches quotidiennes à partir d'un menu dans la console.

## Fonctionnalités
- Ajouter une tâche avec un titre.
- Refuser les titres vides.
- Afficher toutes les tâches avec leur numéro.
- Rechercher une tâche par mot-clé.
- Quitter le programme.

## Étapes réalisées
1. Création du fichier main.py.
2. Développement du programme Python.
3. Test des différentes fonctionnalités.
4. Création du fichier README.md.
5. Gestion du projet avec Git et GitHub.

## Exécution du programme
1. Ouvrir le projet dans Visual Studio Code.
2. Ouvrir le fichier main.py.
3. Cliquer sur le bouton "Run Python File" en haut à droite.
4. Utiliser le menu dans le terminal.

## Technologies utilisées
- Python
- Git
- GitHub
- Visual Studio Code
## Utilisation
- Choisir 1 pour ajouter une tâche.
- Choisir 2 pour afficher les tâches.
- Choisir 3 pour rechercher une tâche.
- Choisir 0 pour quitter l'application.
